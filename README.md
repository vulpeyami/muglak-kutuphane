# Muğlak Kütüphane

Muğlak Taverna hikâyelerinin okuyucu uygulaması (Windows).

## Kurulum
1. [Releases](../../releases/latest) sayfasından `MuglakKutuphane-Setup-*.exe` dosyasını indir.
2. Çalıştır. Windows "bilinmeyen yayıncı" uyarısı verirse **Ek bilgi → Yine de çalıştır**.
3. Kütüphaneden **Prolog** ile başla.
